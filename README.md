# 漂流 POINT NEMO

사자자리 성도를 인터페이스로 삼은 개인 아카이빙 페이지입니다. 별을 누르면 해당 섹션이 열립니다.

빌드 도구나 외부 라이브러리 없이 **HTML 파일 하나로 동작**합니다. 이미지와 배경 사진은 모두 파일 안에 포함되어 있어 별도 자산 폴더가 필요 없습니다.

---

## 파일

| 파일 | 용도 |
|---|---|
| `index_사자자리_암호화.html` | **배포용.** 본문 전체가 암호화되어 있음 (1.64 MB) |
| `index_사자자리.html` | 편집용 원본. 내용이 평문으로 들어 있음 (1.23 MB) |

> **웹에는 암호화 버전만 올리세요.** 평문 원본이 함께 올라가 있으면 암호화가 무의미해집니다. 원본은 로컬이나 비공개 저장소에만 두는 것을 권합니다.

배포할 때는 암호화 파일의 이름을 `index.html`로 바꿔서 올리면 됩니다.

## 잠금

### 진입 비밀번호 — 실제 암호화

배포용 파일은 본문 전체가 **AES-256-GCM**으로 암호화되어 있습니다. 비밀번호에서 **PBKDF2-SHA256(60만 회)** 로 키를 만들어야만 복호화되며, 소스 보기를 해도 암호문만 보입니다.

현재 비밀번호는 `1014` 입니다.

> **비밀번호를 바꾸려면 재암호화가 필요합니다.** 파일 안의 값을 직접 고치면 열 수 없게 되니 주의하세요.
>
> 4자리 숫자는 경우의 수가 1만 개뿐이라, 파일을 내려받아 전부 대입하면 일반 노트북으로 약 25분이면 뚫립니다. 암호화 강도와 무관하게 비밀번호 자체가 짧기 때문입니다. 실질적인 보호가 필요하다면 영문·숫자를 섞은 10자 이상을 권합니다.

### 섹션 잠금 — 화면 가리기

PROMPT 안의 **산도**와 **미스**는 별도 비밀번호(`1014`)로 한 겹 더 가려져 있습니다. 이쪽은 암호화가 아니라 화면을 가리는 방식이라, 진입 비밀번호를 통과한 사람이 개발자 도구를 열면 내용을 볼 수 있습니다.

## 편집

평문 원본(`index_사자자리.html`)을 수정한 뒤 다시 암호화해서 배포합니다. 아래 값들은 파일 안에서 바로 고칠 수 있습니다.

| 값 | 위치 | 현재 | 설명 |
|---|---|---|---|
| `GATE_CODE` | script 상단 | `'1014'` | 진입 비밀번호 (평문 파일 전용) |
| `SECTION_PW` | script | `'1014'` | 산도 · 미스 섹션 비밀번호 |
| `BGM_VIDEO_ID` | script | `'6rb9vWDCLlA'` | 유튜브 영상 ID |
| `SHOW_STARFIELD` | script 상단 | `true` | 별밭 배경 켜기/끄기 |
| `SKY_SCRIM` | 별밭 함수 | `['0','0','0']` | 배경 사진을 덮는 밤하늘 농도 `[중심, 중간, 가장자리]` |
| `BG_PHOTOS` | script 상단 | `[]` | 비우면 파일에 심어둔 사진 사용, 주소를 넣으면 그쪽 우선 |
| `--photo-dim` | style 하단 | `.45` | 배경 사진 위에 덮는 어둠 (0~1) |

배경 사진을 더 선명하게 보고 싶으면 `--photo-dim`을 낮추고, 별이 잘 안 보이면 올리면 됩니다.

## GitHub Pages 배포

1. 저장소에 암호화 파일을 `index.html`로 올립니다
2. Settings → Pages → Source를 `main` 브랜치로 지정합니다
3. 몇 분 뒤 `https://<사용자명>.github.io/<저장소명>/` 에서 열립니다

암호화 해제에 쓰이는 Web Crypto API는 **HTTPS 환경에서만 동작**합니다. GitHub Pages는 HTTPS이므로 문제없고, 그 외 환경에서는 안내 문구가 표시됩니다.

## 참고

- 페이지에 넣는 이미지는 EXIF와 생성 메타데이터를 제거한 뒤 포함했습니다. AI 생성 이미지의 경우 PNG 텍스트 청크와 알파 채널에 프롬프트 전문이 숨어 있을 수 있어, JPEG로 재인코딩해 걷어냈습니다.
